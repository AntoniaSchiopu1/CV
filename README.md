# Portofoliu Antonia Șchiopu

Acesta este proiectul meu de portofoliu personal, creat pentru a-mi prezenta experiența, abilitățile și proiectele într-un mod modern. Proiectul este un portofoliu web dinamic, realizat în timpul facultății.

## Tehnologii folosite
- **HTML5:** Structura semantică a paginii.
- **CSS3:** Stiluri personalizate, design modern de tip "bento-box", animații și design responsiv.
- **PHP:** Utilizat pentru logica de server și gestionarea datelor.

## Structura proiectului
- `index.php`: Pagina principală a portofoliului care conține structura HTML.
- `style.css`: Fișierul dedicat stilurilor și designului vizual.
- `api.php`: Fișierul care gestionează logica serverului și preluarea proiectelor.
- `config.php`: Fișier de configurare pentru setările bazei de date/sistemului.
- `README.md`: Documentația oficială a proiectului.

## Instalare locală
Pentru a rula acest proiect pe calculatorul tău, urmează acești pași:

1. **Cerințe:**
   - Asigură-te că ai instalat **XAMPP** (sau un alt server local precum WAMP).
2. **Clonare/Descărcare:**
   - Descarcă fișierele și plasează-le într-un folder nou (de exemplu: `CV`) în directorul tău local de proiecte (de regulă: `C:\xampp\htdocs\`).
3. **Pornire:**
   - Deschide *XAMPP Control Panel* și pornește **Apache**.
   - Deschide browserul tău preferat și accesează adresa: `http://localhost/CV/`
